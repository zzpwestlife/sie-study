# Chapter 5 Terminology Glossary (Securities Underwriting)
# 第 5 章 术语表（证券承销）

## 1. 核心参与者与机构 (Core Players)

| 英文术语 | 中文标准翻译 | 定义/上下文备注 |
| :--- | :--- | :--- |
| **Issuer** | 发行人 | 筹集资金的实体 |
| **Underwriter** | 承销商 | 负责销售证券的经纪自营商 |
| **Investment Banking Firm** | 投资银行 | 协助发行人融资的机构 |
| **Syndicate** | 承销团 | 共同分担风险的承销商群体 |
| **Managing (Lead) Underwriter** | 管理（主）承销商 | 负责组建承销团并直接与发行人打交道的公司 |
| **Selling Group** | 销售小组 | 协助分销但不承担财务风险的经纪商成员 |
| **Registrar** | 登记代理人 | 负责“计数”，确保发行在外的股份不超过授权量 |
| **Transfer Agent** | 过户代理人 | 负责维护所有权记录、注销/发行证书、分发股息 |

## 2. 法律与注册流程 (Acts & Process)

| 英文术语 | 中文标准翻译 | 定义/上下文备注 |
| :--- | :--- | :--- |
| **Securities Act of 1933** | 1933年证券法 | 监管公司证券的新发行，侧重全面披露 |
| **Securities Exchange Act of 1934** | 1934年证券交易法 | 成立 SEC，监管二级市场、交易所及经纪人 |
| **Trust Indenture Act** | 信托契约法 | 针对 $5,000万 以上的公开债券发行 |
| **Registration Statement** | 注册登记表 | 提交给 SEC 的详细法律与财务文档 |
| **Prospectus** | 招股说明书 | 向投资者披露重大事实的核心销售文档 |
| **Shelf Registration** | 货架注册 / 暂搁注册 | SEC Rule 415，允许发行人分批发行，有效期最长 3 年 |
| **Cooling-off Period** | 冷静期 / 等待期 | 注册表提交后至生效前的审查期（通常 20 天） |
| **Red Herring** | 红鲱鱼招股书 | 即初步招股说明书，因封面红色警告文字得名 |
| **Blue-sky Laws** | 蓝天法 | 州级证券监管法律 |

## 3. 承销协议与类型 (Underwriting Types)

| 英文术语 | 中文标准翻译 | 定义/上下文备注 |
| :--- | :--- | :--- |
| **Firm-commitment** | 包销 | 承销商购入全部证券，承担未售出部分的财务风险 |
| **Best-efforts** | 代销 / 尽力推销 | 承销商不承担风险，仅作为代理人尽力销售 |
| **All-or-None (AON)** | 全额认购或取消 | 代销的一种，未全部卖出则撤销交易 |
| **Mini-max** | 最小-最大承销 | 达到最低门槛即生效，最高有限额 |
| **Standby Underwriting** | 备用承销 | 承销商承诺购买权利发行 (Rights) 中公众未认购的股份 |
| **Negotiated Offering** | 议价发行 | 发行人直接选定承销商并协商条款 |
| **Competitive Offering** | 竞价发行 | 发行人根据投标（Bidding）选择承销商 |

## 4. 豁免与规则 (Exemptions & Rules)

| 英文术语 | 中文标准翻译 | 监管变动标注/备注 |
| :--- | :--- | :--- |
| **Exempt Securities** | 豁免证券 | 如国债、市政债、银行发行的证券等 |
| **Accredited Investor** | 合格投资者 / 认证投资者 | **最新变动**：现包含持有 Series 7/65/66 等执照的专业人士 |
| **Qualified Institutional Buyer (QIB)** | 合格机构买家 | 管理至少 1 亿美元资产的机构 |
| **Rule 147** | 147号规则 (州内发行) | 要求发行人资产/收入/资金流向 80% 在该州内 |
| **Regulation D** | D 条例 (私募) | 限制非合格投资者人数不超过 35 人 |
| **Rule 144** | 144号规则 | 限制性股票与控制性证券的销售规则（含 1% 交易量限制） |
| **Rule 144A** | 144A号规则 | 允许未注册证券在 QIBs 之间快速转让 |
