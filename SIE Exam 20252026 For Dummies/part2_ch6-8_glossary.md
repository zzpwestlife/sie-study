# SIE Part 2 (Chapters 6-8) Consolidated Glossary
# SIE 第2部分（第6-8章）统一术语表

## Chapter 6: Equity Securities (权益证券)

| English Term | Chinese Translation | Notes |
| :--- | :--- | :--- |
| **Statutory voting** | 法定投票 | 每一席位投一票 |
| **Cumulative voting** | 累积投票 | 允许将总票数集中投给一个或多个候选人 |
| **Proxy** | 代理投票 / 委托书 | 股东授权他人代为投票 |
| **Authorized shares** | 授权股份 | 公司章程规定的最大发行量 |
| **Issued shares** | 已发行股份 | 已经售出的股份 |
| **Outstanding shares** | 流通股份 | 投资者持有的股份（已发行 - 库存股） |
| **Treasury stock** | 库存股 | 发行人回购的自有股份 |
| **Forward stock split** | 正向拆股 | 增加股份数量，降低股价 |
| **Reverse stock split** | 反向拆股 | 合并股份，提高股价 |
| **Ex-dividend date** | 除息日 | 购买者不再享有本次股息的日期 |
| **ADR (American Depositary Receipt)** | 美国存托凭证 | 外国公司在美国上市的凭证 |
| **Preemptive rights** | 优先认股权 | 现有股东维持持股比例的权利 |
| **Warrants** | 认股权证 | 长期购买股票的权利，通常作为“甜头” (Sweetener) |

## Chapter 7: Debt Securities (债务证券)

| English Term | Chinese Translation | Notes |
| :--- | :--- | :--- |
| **Maturity date** | 到期日 | 偿还本金的日期 |
| **Coupon rate** | 票面利率 | 固定利息百分比 |
| **Bond indenture** | 债券契约 | 发行人与投资者之间的法律协议 |
| **Trustee** | 受托人 | 保护债权人利益的机构 |
| **Sinking fund** | 偿债基金 | 为偿还债务而拨备的专项资金 |
| **Term bonds** | 到期债券 / 定期债券 | 同一日期全部到期 |
| **Serial bonds** | 分期偿还债券 | 分批次到期 |
| **Mortgage bonds** | 抵押债券 | 以不动产抵押担保 |
| **Equipment trust** | 设备信托 | 以交通设备（飞机、货车）为担保 |
| **Collateral trust** | 抵押信托 | 以其他证券为担保 |
| **Debentures** | 无抵押信用债券 | 仅凭发行人信用担保 |
| **Income bonds** | 收益债券 | 仅在有盈利时支付利息，风险极高 |
| **Nominal yield** | 名义收益率 | 即票面利率 |
| **Current yield** | 当期收益率 | 年利息 / 市场价格 |
| **Yield to maturity (YTM)** | 到期收益率 | 长期投资回报率 |
| **Basis point** | 基点 | 0.01% |
| **Accrued interest** | 应计利息 | 两次付息日之间累计的利息 |

## Chapter 8: Municipal Bonds (市政债券)

| English Term | Chinese Translation | Notes |
| :--- | :--- | :--- |
| **General Obligation (GO) bonds** | 一般责任债券 | 由发行人的征税权支持 |
| **Revenue bonds** | 收益债券 | 由特定项目的收入支持（如收费路、桥梁） |
| **Ad valorem tax** | 从价税 | 通常指财产税 |
| **Industrial development revenue bonds (IDRs)** | 工业发展收益债券 | 由企业租金支持，风险最高 |
| **Negotiated offering** | 议价发行 | 直接选定承销商 |
| **Competitive offering** | 竞价发行 | 通过投标选择最低成本承销商 |
| **Official statement** | 官方声明书 | 市政债的“招股说明书” |
| **Build America Bonds (BABs)** | 建设美国债券 | 可征税但有联邦补贴的市政债 |
| **Tax anticipation notes (TANs)** | 税收预期票据 | 短期融资工具 |
| **529 savings plans** | 529 储蓄计划 | 教育专项储蓄 |
| **ABLE accounts** | ABLE 账户 | 残障人士专项账户 |
| **Taxable equivalent yield (TEY)** | 税收等值收益率 | 用于对比免税市政债与可征税公司债 |
| **Triple tax-free** | 三重免税 | 免除联邦、州、地方三级所得税 |
