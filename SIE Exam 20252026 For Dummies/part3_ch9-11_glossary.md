# SIE Part 3 (Chapters 9-11) Preliminary Glossary
# SIE 第3部分（第9-11章）初步术语表

## Chapter 9: Packaged Securities (组合证券/包装证券)

| English Term | Chinese Translation | Notes |
| :--- | :--- | :--- |
| **Investment Company Act of 1940** | 1940年投资公司法 | 监管投资公司的核心法律 |
| **Management investment company** | 管理型投资公司 | 分为开放式和封闭式 |
| **Mutual fund (Open-end fund)** | 共同基金 / 开放式基金 | 持续发行，按NAV赎回 |
| **Closed-end fund** | 封闭式基金 | 股份数量固定，在二级市场交易 |
| **Face-amount certificate company** | 面值证单公司 | 三类投资公司之一 |
| **Unit investment trust (UIT)** | 单位投资信托 | 三类投资公司之一，组合固定 |
| **Net Asset Value (NAV)** | 基金净值 | 资产减负债除以股数 |
| **Public Offering Price (POP)** | 公开发售价 | NAV + 销售费用 |
| **Sales charge (Load)** | 销售费用 / 申购费 | |
| **No-load fund** | 无销售费基金 | |
| **Class A shares** | A类股 | 前端收费 (Front-end load) |
| **Class B shares** | B类股 | 后端收费 (Back-end load) |
| **Class C shares** | C类股 | 级别收费 / 年度收费 (Level load) |
| **12b-1 fee** | 12b-1 费用 | 营销与分销费用 |
| **Breakpoint** | 起点金额 / 费率折让点 | 达到特定投资额可享受费率优惠 |
| **Letter of Intent (LOI)** | 意向书 | 允许在13个月内分批投入以享受折扣 |
| **Rights of Accumulation (ROA)** | 累计优先权 | 基于现有持仓及新增投资计算折扣 |
| **Exchange-Traded Fund (ETF)** | 交易所交易基金 | |
| **Exchange-Traded Note (ETN)** | 交易所交易票据 | 无担保债务工具 |
| **Annuity** | 年金 | 退休收入工具 |
| **Fixed annuity** | 固定年金 | 保险产品，非证券 |
| **Variable annuity** | 变动年金 | 证券产品，需SEC注册 |
| **Separate account** | 独立账户 | 变动年金资产存放处 |
| **Assumed Interest Rate (AIR)** | 假设利率 | 用于计算变动年金给付额 |

## Chapter 10: DPPs and REITs (私募及不动产信托)

| English Term | Chinese Translation | Notes |
| :--- | :--- | :--- |
| **Direct Participation Program (DPP)** | 直接参与计划 | 通常为有限合伙制 |
| **Limited Partnership (LP)** | 有限合伙 | |
| **General Partner (GP)** | 普通合伙人 | 负责管理，承担无限责任 |
| **Limited Partner (LP)** | 有限合伙人 | 投资者，承担有限责任 |
| **Tax shelter** | 避税工具 | 旧称 |
| **Passive income/loss** | 被动收入/损失 | 合伙制企业的税务特征 |
| **Real Estate Investment Trust (REIT)** | 不动产投资信托基金 | |
| **Equity REIT** | 权益型 REIT | 投资并拥有房产 |
| **Mortgage REIT** | 抵押型 REIT | 投资房产贷款 |
| **Hybrid REIT** | 混合型 REIT | 兼具权益和抵押特征 |

## Chapter 11: Options (期权)

| English Term | Chinese Translation | Notes |
| :--- | :--- | :--- |
| **Call option** | 看涨期权 | 买权 |
| **Put option** | 看跌期权 | 卖权 |
| **Bullish** | 看多 / 牛市心态 | 预期价格上涨 |
| **Bearish** | 看空 / 熊市心态 | 预期价格下跌 |
| **Strike price** | 行权价 / 履约价 | |
| **Premium** | 期权费 / 权利金 | 期权的价格 |
| **In-the-money (ITM)** | 实值期权 | 具有内在价值 |
| **At-the-money (ATM)** | 平值期权 | 行权价等于市价 |
| **Out-of-the-money (OTM)** | 虚值期权 | 无内在价值 |
| **Intrinsic value** | 内在价值 | 实值部分的金额 |
| **Time value** | 时间价值 | 期权费减去内在价值 |
| **Breakeven point** | 盈亏平衡点 | |
| **Opening purchase** | 开仓买入 | |
| **Opening sale** | 开仓卖出 / 写入 | |
| **Closing sale** | 平仓卖出 | |
| **Closing purchase** | 平仓买入 | |
| **Covered call** | 备兑看涨期权 | 持有标的资产并卖出看涨期权 |
| **Uncovered (Naked)** | 无担保 / 裸期权 | |
| **OCC (Options Clearing Corp)** | 期权结算公司 | 发行人和担保人 |
| **ODD (Options Disclosure Document)** | 期权风险披露文件 | |
| **Exercise** | 行权 | |
| **Assignment** | 指派 / 履约指派 | 卖方被要求履行义务 |
